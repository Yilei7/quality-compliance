# Security policy

## Supported versions

Security fixes are currently provided only for the latest published release and the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability involving credentials, personal information, path traversal, evidence disclosure, or unsafe execution.

Send a private report to the repository maintainers using the security contact configured in the GitHub repository. Include a reproducible description, affected version/commit, impact, and a safe proof of concept. Do not include real enterprise data.

The project is local-first. Operators remain responsible for filesystem permissions, backups, malware scanning, and the security of any adapter or service that invokes the JSON API.
