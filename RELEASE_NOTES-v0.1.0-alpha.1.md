# quality-compliance v0.1.0-alpha.1

## What is included

- Shanghai medical-device distribution onboarding;
- baseline diagnosis and qualified-review confirmation workflow;
- recurring checks and evidence association;
- JSON stdin/stdout integration API;
- deterministic release validation and archive build scripts.

## Scope

`CN / 上海市 / device_distribution`, one enterprise per external runtime data directory.

## Regulatory content status

`draft-requires-qualified-review`. This release is a technical reference implementation for controlled pilots. It does not certify compliance or guarantee inspection acceptance.

## Known limitations

- No automatic tracking of regulatory changes;
- no multi-tenant access control, electronic signatures, or regulator submission;
- no legal or regulatory determination;
- national/provincial/municipal applicability still requires qualified review;
- production deployment requires the adopter's own privacy, security, backup, and validation controls.
