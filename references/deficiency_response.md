# 缺陷项应对与 CAPA 整改

## 一、检查前 / 中 / 后

### 检查前（T-30 天）
1. 按 inspection_checklist.md 自查，**缺陷先自查出来先整改**
2. 整理证据包：批记录、检验记录、培训档案、验证报告、偏差/CAPA 台账、供应商档案
3. 模拟飞检（随机抽批记录/偏差/变更，验证可追溯性）
4. 关键岗位人员在岗安排，防止检查期间"人不在"

### 检查中
- **应答原则**：如实回答，问什么答什么；不过度解释、不主动展开；不猜测、不编造
- 文件随要随到，10 分钟内提供；找不到就直说"我去查"，不要现场编
- 记录检查员的提问，不确定的事项记下来会后核实再答复
- 陪同人员不抢答、不打断；技术问题由对口岗位回答

### 检查后
1. 拿到缺陷清单后**当日**开内部会议，逐条确认事实
2. 缺陷分级：
   - **严重缺陷**：直接影响产品质量/用药用械安全、数据造假、体系性缺失 → 立即停产整改
   - **主要缺陷**：较大影响，如验证缺失、关键记录不完整 → 限期整改（通常 30 日）
   - **一般缺陷**：轻微不符合 → 常规整改
3. 按 CAPA 模板出整改报告，按期提交药监部门

## 三、高频缺陷与快速整改要点

| 高频缺陷 | 快速整改动作 |
|---|---|
| 培训记录缺失/考核缺失 | 补组织补训，记录真实时间；修订培训 SOP |
| 校准超期 | 立即送检，期间数据评估（是否影响已放行批次） |
| 偏差未闭环 | 梳理台账，逐条补 CAPA 与验证 |
| 记录修改不规范 | 培训划线更正规范；抽查整改后记录 |
| 计算机系统无审计追踪 | 升级/配置审计追踪；存量数据风险评估 |
| 不良反应迟报 | 立即补报，说明原因；修订上报流程 |
| 供应商资质过期 | 立即更新资质文件，暂停采购直至合格 |
| 账号未注册/信息过期 | 立即注册/更新，截图存档为证据 |
| 年度自查报告未报送 | 立即登录所在地系统补报，截图存档（上海：zssb.yjj.sh.gov.cn） |
