# 现场检查自查清单（模拟飞检用）

> 使用方式：检查前 T-30 天起，按模块逐项核对。每项三态：✅ 有证据 / ⚠️ 部分缺失 / ❌ 缺失。
> 自查结果记录到运行数据目录的 `evidence/inspection_selfcheck_YYYYMMDD.md`，缺陷项转 `references/deficiency_response.md` 模板。

## 1. 机构与人员
- [ ] 组织机构图、质量管理部门独立性（质量受权人/管理者代表任命文件）
- [ ] 岗位职责文件、人员资质档案（学历/职称/培训证书）
- [ ] 年度培训计划 + 培训记录 + 考核记录
- [ ] 健康档案（体检报告、禁忌症调岗记录）
- [ ] 关键岗位人员变更是否报备/更新

## 2. 厂房设施与设备
- [ ] 车间/库房布局图、洁净区压差/温湿度记录
- [ ] 设备台账、状态标识（运行/维修/停用）
- [ ] 校准证书清单（仪器、衡器、温控设备）——**核对有效期**
- [ ] 维护保养计划与记录
- [ ] 空调系统/水系统验证与监测记录（药品生产）

## 3. 物料管理
- [ ] 供应商清单 + 资质文件 + 审计记录（关键物料）
- [ ] 物料验收记录、入库台账、合格证/检验报告
- [ ] 物料状态标识（待验/合格/不合格/退货）
- [ ] 不合格品处理记录、销毁记录
- [ ] 特殊物料（麻醉/精神药品）双人双锁台账

## 4. 生产管理（生产企业）
- [ ] 批生产记录完整性与可追溯性（抽样 2-3 批核对）
- [ ] 清场记录、批号管理、物料平衡
- [ ] 生产指令/工艺规程与注册工艺一致性
- [ ] 偏差处理记录（抽查历史偏差是否闭环）
- [ ] 中间体/半成品储存条件

## 5. 质量控制
- [ ] 检验记录、检验报告书、仪器使用记录（审计追踪）
- [ ] 留样管理（留样量、留样观察记录）
- [ ] 稳定性考察方案与数据
- [ ] 检验方法验证/确认
- [ ] 标准品/对照品管理

## 6. 质量保证
- [ ] 文件体系：SOP 清单、文件版本控制、分发回收记录
- [ ] 变更控制台账（抽查是否完成验证与批准）
- [ ] CAPA 台账（关闭率、有效性验证）
- [ ] 内审报告与整改跟踪
- [ ] 投诉处理记录、召回演练记录
- [ ] 产品质量回顾（年度质量回顾报告）

## 7. 数据完整性
- [ ] 电子数据备份、权限管理、审计追踪启用情况
- [ ] 记录修改规范抽查（有无涂改、无签名修改）
- [ ] 实验室数据（HPLC/GC 等）与纸质记录一致性

## 8. 药物警戒 / 不良事件监测
- [ ] 体系文件、专职人员任命
- [ ] 个例报告及时性抽查（对照销售/投诉记录）
- [ ] 定期报告（PSUR/定期风险评价）提交凭证
- [ ] 年度报告/年度自查报告提交凭证

## 9. 账号与系统（现场可能抽查）
- [ ] 不良反应直报系统可登录、密码未过期
- [ ] UDI 数据已按品类上传
- [ ] 追溯码数据可查询
- [ ] 年度报告系统账号状态正常
- [ ] 上海器械经营企业：上海市医疗器械追溯报告系统可登录（zssb.yjj.sh.gov.cn）

## 检查前准备动作
1. 打印上述清单，逐项核对并归档证据
2. 提前 1 周模拟飞检：随机抽 3 批批记录、3 份偏差、3 份变更，看能否 10 分钟内找到
3. 确认陪同人员分工（质量负责人、生产、仓库、QA/QC 各一人）
4. 准备会议室、检查用文件柜、网络/账号演示环境
