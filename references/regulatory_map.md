# 法规 → 检查项映射

> 本文件用于 Agent 回答"我们XX做到位了吗"时核对检查要点。
> **免责声明**：以下为常见监管要求，具体条款号、时限、账号要求以国家药监局及**所在省药监局**现行规定为准。拿不准时先联网检索法规原文。

## 一、国家局/省级监管系统账号清单

账号类任务的判定标准：**已注册 + 可正常登录 + 企业信息最新**（法人、地址、许可证变更后需及时更新）。

| 账号 | 适用 | 说明 |
|---|---|---|
| 国家药品不良反应监测系统（直报） | 药品生产企业（必须）、药品经营企业 | 个例不良反应在线报告；死亡/严重 15 日、其他 30 日 |
| 药品年度报告系统 | 药品 MAH | 每年 3 月 31 日前提交上年度报告；部分省用省级系统 |
| 药品追溯协同服务平台 | 药品生产/经营 | 追溯码数据对接上传 |
| 国家医疗器械不良事件监测信息系统 | 器械注册人/备案人（必须） | 个例报告、季度/年度汇总、定期风险评价 |
| 国家 UDI 数据库 | 器械注册人（按品类实施时间表） | UDI 编码、包装标识、数据上传 |
| 医疗器械注册电子申报系统（eRPS） | 器械注册人 | 注册/延续注册/变更注册申报 |
| 上海市医疗器械追溯报告系统 | 上海器械注册人/备案人/经营企业 | 每年 2/1-3/31 在线报送上年度自查报告，首次需注册（zssb.yjj.sh.gov.cn） |
| 省级药品生产监管信息系统 | 各省要求不一 | 部分省要求企业信息维护、自查报告在线提交 |

## 二、按模块的检查要点

### 培训
- 年度培训计划是否覆盖全员（含新员工岗前培训、转岗培训）
- 培训内容是否与岗位职责匹配（GMP/GSP 法规、SOP、安全）
- 培训记录：时间、讲师、参加人、内容；**考核记录**（试卷/实操评估）
- 健康档案：直接接触药品/器械人员是否定期体检（通常每年），患有传染病等是否调岗

### 记录管理
- 批生产记录/批检验记录：是否及时、真实、完整、可追溯
- 记录修改：划线更正 + 签名 + 日期，**严禁涂改、撕页**
- 电子记录：计算机化系统是否有审计追踪、权限管理
- 保存期限：药品批记录至少产品有效期后 1 年；器械进货查验/销售记录至有效期后 2 年（无有效期 ≥5 年）

### 验证与校准
- 设备/仪器校准证书是否在有效期内
- 工艺验证、清洁验证、设备确认：方案 → 执行 → 报告 → 批准
- 计算机化系统验证（CSV）：数据完整性
- 冷链：冷库/冷藏车/保温箱验证报告（每年，夏季前）

### 内审与 CAPA
- 年度内审计划、内审方案、内审报告（至少每年一次）
- 内审发现项 → CAPA（纠正预防措施）→ 跟踪验证闭环
- 偏差处理：偏差记录、评估、CAPA、批准

### 变更控制
- 变更申请 → 风险评估 → 验证 → 批准 → 实施 → 记录
- 涉及注册事项的变更（处方、工艺、规格、适用范围）是否申请变更注册

### 药物警戒（药品）
- 药物警戒体系文件、专职人员
- 个例报告：严重 15 日、死亡立即、其他 30 日
- PSUR 按注册周期提交；年度药物警戒报告
- 药品安全风险沟通、风险控制措施

### 不良事件监测（器械）
- 监测制度、专职人员、上报流程
- 死亡/严重不良事件：立即报告 + 调查
- 定期风险评价报告（每年）、年度汇总报告

### 召回与投诉
- 召回制度、召回分级（一/二/三级）、召回报告
- 投诉记录：登记 → 调查 → 处理 → 反馈 → CAPA

## 三、常见"做到位"判定信号（含风险分级）

| 信号 | 判定 | 风险 |
|---|---|---|
| 标 completed 且证据文件存在 | ✅ 到位 | 低 |
| 标 completed 但 evidence/ 无证据文件 | ⚠️ 疑似口头完成，需补证据 | 中 |
| next_due 已过且未完成 | ❌ 超期 | 高 |
| 30 天内到期 | 🟡 临近 | 中 |
| 强制账号 registered=false | ❌ 未注册（法规义务） | 高 |
| 账号 registered=null | ⬜ 未确认 | 中 |

每个结论必须走证据溯源面板（SKILL.md）：📜 法规依据 → 📋 任务状态 → 📎 证据文件，缺失的环节明确标出，不允许只给一句"看起来没问题"。
