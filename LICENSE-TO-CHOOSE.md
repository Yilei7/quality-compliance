# Licence decision required before publication

The current package manifest intentionally leaves `distribution.license` unset. Choose and document a licence before making the repository public.

Recommended starting point, subject to owner/legal review:

- source code and scripts: Apache-2.0 or MIT;
- original documentation and original task metadata: CC BY 4.0 or the same code licence;
- third-party regulatory material: retain its original licence/terms and do not relicense it;
- ISO/IEC/GB/YY standards: reference them, but do not redistribute the text unless you have explicit permission.

After the decision, add the corresponding licence files, update `manifest.json`, and record third-party notices in `NOTICE`.
